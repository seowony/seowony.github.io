# seowony.github.io

Personal website for Seo-Won Chang — https://seowony.github.io/

Static HTML on GitHub Pages. No build step. Edit the HTML, commit, push.

```
index.html            home page (HTML + CSS + inline SVG in one file)
gallery.html          KS4 images and photos of places
arp.html              Arp atlas in KS4 (generated by tools/make_arp_gallery.py)
arp_template.html     template used to generate arp.html
places.html           redirect to gallery.html#places (old link)
stories/gw170817.html the night of GW170817, with a four-panel cartoon
cv.tex / cv.pdf       web version of the CV — no referee details, no address, no grant amounts
assets/               images and videos (assets/arp/ is created by the Arp script)
tools/                helper scripts
```

The full CV — with references, office address and grant amounts — is kept offline and is not
in this repository.
